# Развёртывание: снять привязку к компьютеру

Система, которая работает только при открытом ноутбуке, — это не автоматизация,
а работа с лишними шагами. Агент должен жить на сервере круглосуточно, а
подтверждения приходить оператору в телефон.

Порядок такой: сначала телефон, потом сервер. Первое даёт свободу передвижения
за пять минут, второе — круглосуточную работу.

## Шаг 1. Подтверждения в телефон · пять минут

1. Открыть Telegram, найти **@BotFather**, отправить `/newbot`, придумать имя.
   Он вернёт токен вида `1234567890:AA...`.
2. Найти **@userinfobot**, отправить ему любое сообщение — он пришлёт ваш `Id`.
3. В панели: **Настройки → Подтверждения в телефон** — вписать токен и `Id`,
   сохранить, нажать **«Проверить связь»**. В Telegram должно прийти сообщение
   «Kepil на связи».
4. Перезапустить панель, чтобы включился приём нажатий.

После этого каждое необратимое действие приходит карточкой с двумя кнопками:
что за шаг, какому клиенту, что уйдёт наружу и что будет, если отменить.
Решение принимается с телефона; в панели оно появляется сразу.

Кнопку принимает только тот чат, что указан в настройках: иначе нажать смог бы
любой, кто нашёл бота.

## Шаг 2. Сервер · час

Требование не техническое, а правовое: персональные данные клиентов и их
контрагентов хранятся на инфраструктуре в Казахстане. Подойдёт любой местный
провайдер виртуальных серверов; для начала хватит машины за несколько тысяч
тенге в месяц.

```bash
# на сервере, от отдельного пользователя
git clone <адрес репозитория> kepil && cd kepil
python -m venv .venv && . .venv/bin/activate
pip install -e .
KEPIL_DATA=/var/lib/kepil python -m kepil.admin 7317
```

Автозапуск через systemd — `/etc/systemd/system/kepil.service`:

```ini
[Unit]
Description=Kepil
After=network.target

[Service]
User=kepil
WorkingDirectory=/opt/kepil
Environment=KEPIL_DATA=/var/lib/kepil
ExecStart=/opt/kepil/.venv/bin/python -m kepil.admin 7317
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now kepil
```

## Шаг 3. Доступ снаружи

Панель слушает только `127.0.0.1` — наружу её выставляет обратный прокси с
сертификатом. Без него не открывать: панель управляет агентами и содержит
данные заказчиков.

Минимум, который нужно сделать до первого клиента:

- домен и сертификат (Let's Encrypt);
- доступ по паролю на уровне прокси;
- резервное копирование каталога `KEPIL_DATA` — там весь журнал;
- закрытый порт 7317 в файрволе.

## Что можно сделать раньше сервера

Для показа на встрече сервер не нужен: панель на ноутбуке плюс подтверждения в
телефоне уже снимают привязку к рабочему месту. Временный туннель наружу
(например, `cloudflared`) годится, чтобы показать экран удалённо, но **не для
работы с настоящими данными заказчика** — трафик пойдёт через чужую
инфраструктуру за пределами страны.

## Порядок для первого клиента

1. Telegram — сразу, до первого звонка.
2. Ноутбук — для показа на встрече и первой недели вручную.
3. Сервер — в день, когда клиент говорит «продолжаем»: с этого момента данные
   становятся его, а не учебными.
